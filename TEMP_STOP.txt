### 4️⃣ Configurar .env

### 5️⃣ Obter Facebook Access Token
1. Acesse https://developers.facebook.com/
2. Crie um app (Business → Other)
3. Adicione o product "Graph API"
4. Vá em Tools → Graph API Explorer
5. Gere um token com scopes: public_profile, pages_show_list
6. Copie o token e coloque no .env

**⚠️ Nota:** A API de Ads Library pode precisar de revisão/approval do Meta.

### 6️⃣ Obter Google API Key (Opcional)
1. Acesse https://console.cloud.google.com/
2. Crie um projeto
3. Habilite "Custom Search API"
4. Crie uma API Key
5. Crie um Custom Search Engine em https://programmablesearchengine.google.com/
6. Copie o Search Engine ID
